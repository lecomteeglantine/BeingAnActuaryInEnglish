BUGS / RISKS FOUND AND FIXED
1. PWA stale-version risk
   - Reworked the service worker so page navigations prefer the network and fall back to cache offline.
   - Static assets use cache + network refresh instead of blindly serving an old build forever.
   - Added skipWaiting() and clients.claim() and bumped the cache version.
   - Restricted runtime caching to same-origin GET requests.
   - Failed asset requests no longer receive index.html as fake CSS/JS responses.

2. Inconsistent PWA metadata
   - Added theme colour, description, manifest, favicon and Apple touch icon consistently to all 22 pages.
   - Added PWA registration to pages that previously could not register the service worker when visited first.
   - Neutralised the manifest app name to “Actuarial English” and added explicit scope.

3. Accessibility inconsistencies
   - Added a working Skip to main content link and main#main target to every page.
   - Added accessible labels to unlabelled search/filter/notes controls.
   - Added aria-current to the active navigation item.
   - Improved the accessibility panel with aria-expanded, Escape-to-close and click-outside closing.
   - Added clear :focus-visible styling and automatic prefers-reduced-motion support.
   - Added keyboard semantics/labels to flashcards.
   - Disabled Previous/Next session endpoints are no longer keyboard-actionable links.

4. Mobile navigation
   - On small screens the main navigation now scrolls horizontally instead of wrapping into a large block.
   - Removed the fixed brand minimum width on narrow screens.
   - Improved flashcard sizing and footer clearance on phones.

5. Games reliability
   - Fixed a real answer-collision case: “coverage” and “hedging” both translate as “couverture”; duplicate visible MCQ labels are now excluded from the same question.
   - Correct answers are now marked by item identity rather than matching button text.
   - Category selection now keeps the target words inside the selected category instead of silently falling back to all categories.
   - Locked category/question controls during a round so a mid-game change cannot corrupt later questions.
   - Replaced biased array sorting with Fisher-Yates shuffling.
   - Disabled answered choices to prevent double scoring.
   - Speech is cancelled when leaving an audio round.
   - “Questions” is now labelled “Maximum questions” because small categories can contain fewer terms than the selected maximum.

6. Dictionary / notebook resilience
   - Hardened localStorage reads against malformed or unavailable browser storage.
   - Dictionary save buttons update without rerendering the whole page and losing focus.
   - Added a clear no-results state.
   - Notebook removal/listening controls are explicit and keyboard accessible.
   - Clearing notebook notes now asks for confirmation when notes are non-empty.

7. Flashcards
   - Added the missing Listen control promised by the site copy.
   - Added safe handling for an unexpectedly empty vocabulary file.
   - Improved shuffle quality and accessibility labels.

8. Session vocabulary integrity
   - Found five session tags that did not map to exact dictionary entries:
     data; distribution; generalised linear model; recommendation; materiality.
   - Added all five as proper dictionary entries with British-English IPA, French translation, definition and contextual example.
   - Dictionary now contains 79 complete entries.

9. 404 / utility pages
   - 404 now has the normal navigation, footer, accessibility tools and PWA registration.
   - Privacy and Accessibility pages now use the same technical shell as the rest of the site.
