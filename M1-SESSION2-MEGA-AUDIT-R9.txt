REAL BUGS FIXED IN R9
1. Stale anti-double-click locks after a full rerender
   R8 could still swallow a legitimate repeated action on a newly-rendered control,
   e.g. Final -> Review -> Save -> Review again very quickly.
   R9 clears obsolete DOM locks at every full render while keeping the sound/timer
   guards that do not rerender the interface.

2. Parseable but invalid current save masking a valid older save
   R8 fell back to legacy data only when the current JSON could not be parsed.
   If the current key contained parseable but structurally invalid data, a still-valid
   R8/R6 save could be ignored and the team could appear to lose progress.
   R9 now selects the first VALID state across R9 and all legacy keys.

3. Wrong completion sound after revalidating an earlier gallery
   R8 chose the Final sound from the gallery number. Revalidating Gallery I/II/III after
   a Final review could reopen Opening Night while playing a normal gallery-complete sound.
   R9 chooses the sound from the actual result: if all four galleries are complete, the
   Final sound is played regardless of which gallery was just revalidated.

4. Static asset cache hardening
   Session 2 SVG and WAV references now carry ?v=r9. This prevents an existing browser /
   service-worker cache from silently displaying an older illustration or audio file after
   a GitHub update while keeping the physical asset filenames unchanged.
