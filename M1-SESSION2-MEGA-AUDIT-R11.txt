R11 fixes
1. Anti-double-click / rerender race hardened
- Action locks now use unique tokens.

2. Voice feedback hardened
- If Speech Synthesis is unavailable, “Hear the curator briefing” now gives an explicit message instead of failing silently.
- Sound effects remain available independently.

3. Sound-state async race hardened
- A delayed “Sound ON” test can no longer display a stale ON message after the user has already switched sound OFF.

4. Saved-state hardening
- Boolean fields are now restored strictly instead of accepting truthy strings from malformed/corrupted storage.
- finalScript and gallery pitch notes are safely length-limited during restore.
- Legacy saves without pitchEdited information preserve existing non-empty notes rather than risking accidental overwrite.

5. Keyboard/accessibility hardening
- Each answer group now behaves as a proper roving radio group: one Tab stop per question, arrow keys move selection.
- This avoids forcing keyboard users through all 16 answer buttons with Tab.

6. Pitch clarity consistency
- Exact role names are now consistent between team setup, Pitch Notebook and final speaker plan.
- Final instructions explicitly require each gallery section to link its evidence to the wider museum story.
- Custom gallery notes allow more character room while still enforcing the 30–40 word limit.
- The final-script “too short” warning now matches the stated 170-word lower target.
