KEY RULES BUILT IN
- Students choose 3 or 4 players.
- Every player receives a distinct role.
- No "read it out loud" instruction.
- Six professional email situations + a final email builder.
- Fixed deterministic scoring: no Math.random(), no random branches, no device-dependent logic.
- Same choices on different devices => same feedback, same following screens and same score.
- Restart from zero clears the whole game state.
- Responsive layout for phone, tablet and desktop.
- No account, analytics, remote database or student data collection.

SOURCE CONTENT
The language focus is based on the supplied lesson "Formal and Informal Language in Professional Emails": register continuum, reader/relationship/action/risk, tactful requests, precise deadlines, clarity, concision and adapting the same facts to different readers.
