ACCESSIBILITY

Adapt the site to your needs

Use the ♿ button at the bottom-right of any page to enable larger text, higher contrast or reduced motion.

Keyboard

Links, buttons, form fields and learning controls can be reached with the keyboard. Interactive elements use native HTML controls wherever possible.

Readable layout

The site uses responsive layouts, large touch targets and high-contrast text. Content reflows on small screens instead of requiring horizontal scrolling.

Motion

Reduced motion removes transitions and smooth scrolling for users who prefer a more static interface.

Audio

Pronunciation audio is an optional aid. Definitions and IPA remain visible, so core vocabulary content does not depend on audio.
